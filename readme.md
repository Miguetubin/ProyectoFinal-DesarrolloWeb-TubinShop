# Cómo iniciar el proyecto

1. Abrir la carpeta en VS Code.

2. Abrir una terminal.

3. Ejecutar:

sass --watch sass/main.scss:css/main.css

4. Programar normalmente.

#//GIT COMANDOS//#

git add .	Prepara todos los cambios para el próximo commit.
git commit -m "mensaje"	Guarda una nueva versión (una "foto") del proyecto con un mensaje descriptivo.
git push origin main	Sube esa nueva versión a GitHub.
